# 08 · 云端工作流：给文案就出片

目标：在 Claude Code 云端（claude.ai/code，手机/网页都能发起）只丢一段文案或一个主题，Claude 自己完成
**研究热点 → 写分镜 → 配音 → 找实拍素材 → 渲染 → 验收 → 推到 GitHub**。本机 Mac 不用开。

## 一、一次性设置（你来做）

### 1. 环境网络白名单（最关键）
Claude Code 云端默认只放行包管理器等少数域名。在会话标题栏的云端环境菜单 → Edit → **Network access** 里加上：

| 域名 | 用途 | 不放行会怎样 |
|---|---|---|
| `speech.platform.bing.com` | edge-tts 配音（云扬等音色） | **只能出机械音排版预览**，不能发布 |
| `api.pexels.com` `videos.pexels.com` `images.pexels.com` | Pexels 实拍视频/照片 | 该段退回代码背景 |
| `pixabay.com` `cdn.pixabay.com` | Pixabay 实拍视频/照片 | 同上 |
| `commons.wikimedia.org` `upload.wikimedia.org` | 真实公司/人物/产品照片 | 同上 |
| `push2his.eastmoney.com` 等东财域名 | akshare 行情（技术面 K 线） | 不能自动抓 K 线 |

或者直接把访问级别改成更宽的一档（说明见 https://code.claude.com/docs/en/claude-code-on-the-web）。
热点和基本面检索用的是 Claude 自带的 WebSearch，**不需要**放行。

### 2. 素材 API key（可选，免费）
- Pexels: https://www.pexels.com/api/ → `PEXELS_API_KEY`
- Pixabay: https://pixabay.com/api/docs/ → `PIXABAY_API_KEY`

在同一个环境设置的 **Environment variables** 里加。没有 key 时只用 Wikimedia（无需 key，照片为主）。

### 3. 开会话
新建云端会话时选中 `ychenfen/investment-video-studio`。会话启动时 `.claude/settings.json` 的 SessionStart hook
自动跑 `scripts/cloud/setup.sh`（装 ffmpeg / 思源黑体 / espeak-ng / Python 依赖 / Remotion 依赖，首次约 2–3 分钟）。

## 二、日常怎么用（直接对 Claude 说）

- "用这段文案做个视频：……"
- "做一期寒武纪基本面的视频"
- "最近 A 股有什么热点，挑一个有基本面可讲的做视频"
- "这段背景换成我上传的 xx.mp4"（文件放 `projects/<slug>/assets/`）

Claude 按 `.claude/skills/hot-topics` 和 `.claude/skills/make-video` 执行，最后把 mp4 发给你并推到分支。

## 三、管线

```
projects/<slug>/script.json
   │ lint.py      结构 / 数据必须有来源 / 禁用语 / 免责声明
   │ vo.py        配音 + 句级时间轴   (edge → kokoro → espeak 自动降级; silent 只估时长)
   │ media.py     背景素材           (自带文件 → 指定链接 → Pexels → Pixabay → Wikimedia; 记录作者/许可)
   │ props.py     合成 props.json + 按用字做思源黑体子集
   │ ffmpeg       人声 + 配乐侧链闪避, -14 LUFS, 48k 立体声
   │ remotion     Explainer 组件渲染 1080×1920 30fps
   └ check.sh     流参数 / 时长 / 响度 + 4 张抽帧
output/<slug>.mp4
```

画面类型：`title` 封面 · `news` 热点卡 · `numbers` 指标卡(数字滚动) · `bars` 柱状(负值绿柱) · `line` 折线 ·
`compare` 多空对比 · `point` 金句 · `poll` 结尾 A/B/C/D 选项引导评论 · `media` 纯实拍。每段都可以叠背景实拍视频或照片（自动压暗 + 慢推镜 +
右上角标"实拍/资料画面/示意" + 底部素材署名）。字段说明见 `.claude/skills/make-video/SKILL.md`，
完整示例 `projects/cambricon-fundamentals/`。

## 四、云端已验证 / 未验证

已在云端容器验证（2026-09-25）：
- 环境：setup.sh 装齐工具；Remotion 用 Playwright 自带 `headless_shell` 渲染（系统 chromium 不支持旧 headless 模式）
- 管线：lint → 配音(espeak) → 素材(本地文件: 视频循环 + 照片推镜) → props/字体 → 混音 → 渲染 → 验收 全通
- 旧 FupanStory 也能在云端渲染（`scripts/fupan/run.sh` 已改为自动找浏览器、云端走 HTTPS_PROXY）

未验证（云端被网络策略拦截，放行后第一次跑时请留意）：
- edge-tts 真实配音（代码已处理云端代理的 TLS 证书问题）
- Pexels / Pixabay / Wikimedia 自动搜索下载

## 五、踩坑记录
- `npm ci` 卡住：锁文件里是 `registry.npmmirror.com`，云端被拦 → `--registry=https://registry.npmjs.org/ --replace-registry-host=registry.npmmirror.com`
- Remotion 自己下载 chrome-headless-shell 会访问 `remotion.media`（被拦）→ 用 `/opt/pw-browsers/chromium_headless_shell-*/chrome-linux/headless_shell`
- edge-tts 只信 certifi 证书 → 云端代理重签 TLS 会失败；vo.py / make_vo.py 在有 `SSL_CERT_FILE` 时改用它
- 云端没有思源黑体 → apt `fonts-noto-cjk fonts-noto-cjk-extra`（Black 字重在 extra 包里）
