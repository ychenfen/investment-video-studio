# 完整流程：从零到一支投研视频

每一步的命令。环境前提见 03 文档，依赖见 01 文档。所有命令在 macOS / M4 Pro 实测。

## 总览

```
环境准备 → 爬素材(视频/股票/配音/BGM) → 写 Remotion 组件 → 渲染各段 → ffmpeg 拼接 → 验收
```

## 第 0 步：环境（一次性）

```bash
# 系统工具
brew install yt-dlp          # 最新版, 过 YouTube 反爬
# (ffmpeg / cliclick 已有)

# Remotion 项目 + 依赖 (npmmirror 源)
mkdir remotion && cd remotion && npm init -y
npm i remotion@4.0.469 @remotion/cli@4.0.469 @remotion/three@4.0.469 @remotion/fonts@4.0.469 \
      three@0.169.0 @react-three/fiber@8 @fontsource/poppins @fontsource/lora react@18 react-dom@18 \
      --legacy-peer-deps --registry https://registry.npmmirror.com

# Python TTS / 股票数据 (python3.13 + 阿里源)
/opt/homebrew/bin/python3.13 -m pip install --user --break-system-packages edge-tts akshare \
      -i https://mirrors.aliyun.com/pypi/simple

# 本地字体 (gstatic 被墙, 用 @fontsource woff2)
mkdir -p public/fonts
cp node_modules/@fontsource/poppins/files/poppins-latin-{400,600,700}-normal.woff2 public/fonts/poppins-{400,600,700}.woff2
cp node_modules/@fontsource/lora/files/lora-latin-{400,500}-normal.woff2 public/fonts/lora-{400,500}.woff2
```

## 第 1 步：爬中央视频

见 `scripts/1-fetch-jensen-video.sh`。核心：

```bash
export http_proxy=http://127.0.0.1:7897 https_proxy=http://127.0.0.1:7897   # 小写, ffmpeg 才认
/opt/homebrew/bin/yt-dlp --cookies-from-browser chrome --no-warnings \
  --download-sections "*00:12:00-00:12:40" \
  -f "bv*[height<=1080]+ba/b[height<=1080]" --recode-video mp4 \
  -o "/tmp/jensen_raw.mp4" "https://www.youtube.com/watch?v=q_umfWm8J28"
# 截取架构图段, 去音频, 放 public
ffmpeg -y -ss 8 -t 16 -i /tmp/jensen_raw.mp4 -an -c:v libx264 -crf 16 public/center-video.mp4
```

## 第 2 步：抓真实股票数据

见 `scripts/2-fetch-stock-data.py`。核心：akshare 抓 NVDA + 寒武纪日线 OHLCV，存 `src/stockData.json`。

```bash
env -u http_proxy -u https_proxy /opt/homebrew/bin/python3.13 scripts/2-fetch-stock-data.py
```

## 第 3 步：生成配音 + 拿每句时长

见 `scripts/3-gen-voiceover.sh`。核心：edge-tts 云扬逐句生成，ffprobe 拿每句时长（**字幕要按这个时长对齐**），拼接成段配音。

```bash
EDGE=~/Library/Python/3.13/bin/edge-tts
export http_proxy=http://127.0.0.1:7897 https_proxy=http://127.0.0.1:7897
"$EDGE" --proxy http://127.0.0.1:7897 --voice zh-CN-YunyangNeural --rate +6% \
  --text "今天聊聊黄仁勋台北GTC演讲。" --write-media public/vo.mp3
ffprobe -v error -show_entries format=duration -of csv=p=0 public/vo.mp3   # 拿时长 -> 算字幕帧
```

口播音色（edge-tts）：云扬 `zh-CN-YunyangNeural`(新闻男声,推荐) / 云健 `YunjianNeural` / 晓晓 `XiaoxiaoNeural`(女) / 云希 `YunxiNeural`。

## 第 4 步：BGM + 音效

见 `scripts/4-gen-bgm-sfx.sh`。BGM 从 YouTube NCS 下，音效 ffmpeg 合成。

## 第 5 步：写/改 Remotion 组件

`src/` 下。关键约定：
- 字幕时间 = 配音每句时长累加（句间留 0.3s=9帧）。组件里 `SUBS` 数组的 from/to 按这个填
- 中央内容区背景**不透明**（`rgba(14,15,18,0.96)`），挡住 WebGL 水波
- 背景用 `<WebGLGrid />`（水波）；中央视频用不透明 `OffthreadVideo`
- 品牌色/字体在 `theme.ts`

在 `Root.tsx` 注册 composition（id / 组件 / durationInFrames / 30fps / 1080×1920）。

实时预览：`npx remotion studio`

## 第 6 步：渲染各段

见 `scripts/5-render-and-concat.sh`。每段：

```bash
npx remotion render src/index.ts <CompositionId> out/<段>.mp4 \
  --browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --concurrency=1 --crf 16 --timeout=120000
```

**必带** `--browser-executable`(系统Chrome) + `--concurrency=1`(防多tab崩)。WebGL 段较慢，可后台跑。

## 第 7 步：拼接 + 验收

```bash
# 拼接三段 (concat filter 重编码, 处理参数差异)
ffmpeg -y -i out/news.mp4 -i out/nvda.mp4 -i out/cam.mp4 \
  -filter_complex "[0:v][0:a][1:v][1:a][2:v][2:a]concat=n=3:v=1:a=1[v][a]" \
  -map "[v]" -map "[a]" -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 18 \
  -c:a aac -b:a 192k -ar 48000 -movflags +faststart out/full-video.mp4

# 验收 (详见 VIDEO_PRODUCTION_SOP.md §7)
ffprobe -v error -select_streams v:0 -show_entries stream=codec_name,width,height,r_frame_rate -show_entries format=duration out/full-video.mp4
```

## 节奏调整速查

- 改旁白文案 → 改 `scripts/3` 的文本 → 重生成配音 → 拿新时长 → 改组件 SUBS 时间 → 重渲
- 换股票 → 改 `scripts/2` 的 symbol → 重抓 → 改组件标的名/标注 idx → 重渲
- 换中央视频 → 改 `scripts/1` 的 URL/时间段 → 重截 → 重渲
