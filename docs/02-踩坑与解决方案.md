今晚趟过的全部坑，按"现象 → 原因 → 解决"记。这是本工作台最有价值的部分，下个项目照着躲。

## A. 剪映相关

### 1. 剪映新版草稿打不开（自制草稿）
- 现象：pyJianYingDraft 生成的草稿，剪映双击弹"无法打开草稿"
- 原因：剪映 6.0+ 把核心 `draft_info.json` 加密了（base64 + 对称加密），用户是 10.3.0。pyJianYingDraft 只支持 ≤5.9 明文草稿
- 解决：**放弃剪映，改用 Remotion 全代码**。详见 05 文档

### 2. cliclick 操作剪映焦点丢失
- 现象：cliclick 点剪映坐标，结果点到了 Claude 自己的窗口
- 原因：每跑一次 Bash，终端/Claude 抢到前台覆盖剪映
- 解决：点击前先 `osascript -e 'tell application "System Events" to tell process "VideoFusion-macOS" to set frontmost to true'` 激活剪映，和点击放同一条命令

## B. Remotion 渲染（最密集的坑）

### 3. chrome headless shell 下载卡死
- 现象：`npx remotion render` 卡在下载，`~/.remotion` 缓存空，进程 CPU 0.1% 死等
- 原因：Remotion 自带 chrome headless shell 从 google storage 下载，被墙
- 解决：用系统 Chrome 当渲染引擎，加 `--browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`

### 4. 字体加载导致 headless setup 超时
- 现象：`Timed out after 30000ms while setting up the headless browser`
- 原因：@remotion/google-fonts 在 chrome 内请求 gstatic 加载字体，gstatic 被墙，页面 hang
- 解决：不用网络字体，改本地 woff2（@fontsource）+ @remotion/fonts 加载

### 5. delayRender 裸放模块顶层 → bundle 炸
- 现象：bundle 阶段报错，堆栈指向 `const handle = delayRender(...)`
- 原因：模块顶层的 `delayRender` + `new FontFace` + `document.fonts` 在 bundle 评估时（Node 环境，无 document）执行，炸
- 解决：用 `@remotion/fonts` 的 `loadFont({family, url: staticFile(...), weight})`，它内部处理了环境检查

### 6. Remotion 包版本错配 → 渲染页面崩
- 现象：`Error: Visited "http://localhost:3001/index.html" but got no response`，日志有 "all Remotion packages should point to the same version"
- 原因：remotion/transitions 是 4.0.471，cli/fonts 是 4.0.469，混版。cli 是渲染工具，版本必须和 remotion 一致
- 解决：全统一到 4.0.469（npmmirror 上 cli 没有 471）：`npm i remotion@4.0.469 @remotion/transitions@4.0.469 ...`

### 7. 多 tab 并发 + 系统 Chrome 不稳 → got no response
- 现象：版本统一后还是 "got no response"，字体加载日志显示 Tab 0 / Tab 1（多 tab）
- 原因：Remotion 默认多 chrome tab 并发渲染，系统 Chrome（非专用 headless shell）多 tab 不稳，某 tab 崩
- 解决：`--concurrency=1` 单并发。已写进 remotion.config.ts：`Config.setConcurrency(1)`

### 8. jpeg 中间帧把画面压糊
- 现象：成片中央视频/小字糊，但源很清晰
- 原因：`Config.setVideoImageFormat('jpeg')` 让每帧先存 jpeg（有损）再编码，压糊了
- 解决：改 `Config.setVideoImageFormat('png')`（无损中间帧）+ 渲染加 `--crf 16`

### 9. 场景切换硬切空屏闪烁
- 现象："经常闪屏"，场景切换时一闪
- 原因：每个场景开头元素 opacity 从 0 淡入（空屏帧），场景间硬切 = 满→空→满
- 解决：用 `TransitionSeries` + `fade()` 交叉淡入，背景兜底，消除空屏。验证：切换区帧从 9KB(空屏) 变 200KB+(满内容)

### 10. WebGL 在 headless 系统 Chrome 渲染
- 现象：担心 WebGL/Three shader 在 headless 渲染不出（黑屏）
- 原因：headless chrome 默认无 GPU
- 解决：`Config.setChromiumOpenGlRenderer('angle')` + 系统 Chrome，实测渲染出水波 shader（91 帧测试通过）。**这条是意外能通的关键**

### 11. WebGL 水波盖住中央内容
- 现象：背景波浪透过半透明的 K 线卡片，盖住内容
- 原因：中央内容区背景是 `rgba(0,0,0,0.4)` 半透明，波浪透出
- 解决：中央内容区背景改近不透明 `rgba(14,15,18,0.96)`；视频段中央用不透明 OffthreadVideo 自然挡住

## C. 爬数据（yt-dlp / 网络）

### 12. yt-dlp YouTube "not available on this app"
- 现象：搜到视频但报这个错
- 原因：yt-dlp 版本旧，跟不上 YouTube 反爬
- 解决：`brew install yt-dlp` 更新到最新（2026.03.17），用 `/opt/homebrew/bin/yt-dlp`

### 13. YouTube "Sign in to confirm you're not a bot"
- 现象：最新 yt-dlp 还是被挡，要 cookies
- 原因：YouTube bot 验证，要登录态 cookies
- 解决：`--cookies-from-browser chrome`（从系统 Chrome 读 cookies，需 Chrome 登录过 Google）。注意：safari cookies 会报 "Operation not permitted"（容器权限），用 chrome

### 14. 某些 YouTube 视频仍触发 bot 验证（反爬随机）
- 现象：黄仁勋视频能下，BGM 视频又被挡
- 解决：加 `--extractor-args "youtube:player_client=web,mweb,tv"` 换客户端绕过

### 15. ffmpeg 拉 googlevideo 流超时
- 现象：yt-dlp 找到格式了，ffmpeg 切片段时 `Operation timed out`
- 原因：yt-dlp 自己走代理，但 `--download-sections` 调 ffmpeg 拉流，ffmpeg 没走代理
- 解决：设**小写** `http_proxy`/`https_proxy` 环境变量（ffmpeg 只认小写，大写 HTTP_PROXY 不行）

### 16. stooq 下 NVDA 要 apikey
- 现象：`curl stooq.com/q/d/l/?s=nvda.us` 返回要 apikey + captcha
- 解决：换 akshare 抓美股（`ak.stock_us_daily(symbol='NVDA')`）

### 17. akshare 接口不稳 / 限流
- 现象：`RemoteDisconnected` / `HTTP 412`，连续抓被断
- 原因：新浪美股接口不稳、东财连续抓限流、bilisearch 风控
- 解决：① A股用东财 `stock_zh_a_hist`、美股用新浪 `stock_us_daily`，单次抓别连发；② 抓到的数据立刻存 JSON，限流了用已抓的；③ akshare 调用前 `env -u http_proxy -u https_proxy`（国内接口别走代理）

## D. 环境

### 18. pip 清华源 SSL 失败
- 现象：`SSLError ... EOF occurred in violation of protocol`
- 原因：LibreSSL 兼容问题 + 清华源
- 解决：换阿里源 `-i https://mirrors.aliyun.com/pypi/simple`

### 19. Python 3.9 装不了 edge-tts
- 现象：`No matching distribution found for edge-tts`
- 原因：edge-tts 新版要 Python 3.10+，系统 3.9 太老
- 解决：用 `/opt/homebrew/bin/python3.13` + `--break-system-packages`

### 20. 中文字体方块风险
- 现象：担心 Remotion 渲染中文是方块
- 解决：用系统 PingFang SC（`font-family: "PingFang SC"`），系统 Chrome 渲染能访问系统字体，实测正常不方块
