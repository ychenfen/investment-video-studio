# 06 · 复盘故事视频（小于 & 阿本 · 赚钱效应）

竖屏 1080×1920、56 秒的"剧情 + 图解"复盘知识视频：两个原创角色（小于 / 阿本）用对话讲清"复盘先看赚钱效应"。**画面全部由代码生成**，不需要实拍素材、不需要图片/视频生成模型；配音驱动一切时机，改文案重跑一条命令就自动重排。

Remotion 合成 ID：`FupanStory`

```
scripts/fupan/
├── script.json      ← 唯一需要改的文件: 文案/角色/关键词/配音音色
├── make_vo.py       配音(edge-tts | Kokoro) + 句级时间轴 timing.json
├── build.mjs        画面生成器: 场景 DOM + 作用域 CSS + GSAP 编排
├── chars.mjs        原创人物生成器(发型/服装/表情/口型可配)
├── subset.py        思源黑体按用字做子集(3 字重 ~110KB/个)
├── mix.py           配乐(和弦随剧情)/人声闪避/高潮蓄力/卡点音效
├── run.sh           一键: 配音 → 画面 → 字体 → 混音 → 渲染
└── work/            中间产物(gitignore)
remotion/src/fupan/
├── FupanStory.tsx   Remotion 组件: 注入 DOM, 每帧 seek GSAP 时间线
└── generated/       build.mjs 的输出(已提交, 不跑 python 也能直接渲染)
remotion/public/fupan/  mix.mp3 + 子集字体
```

## 一、直接渲染（不改任何东西）

```bash
cd remotion
npx remotion render src/index.ts FupanStory ../output/复盘看赚钱效应.mp4 \
  --browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --concurrency=1 --crf 18
# 或预览: npx remotion studio  → 左侧选 FupanStory
```

## 二、改文案 → 一键重生成

1. 改 `scripts/fupan/script.json`。每句：
   - `s` 角色：`narr` 旁白 / `aben` 阿本 / `xiaoyu` 小于（字幕前会带说话人头像 + 口型）
   - `t` 字幕文本；`hl` 金色高亮关键词（念到时弹一下）；`end: true` 句末停顿更长
   - `tts` 可选，发音修正：字幕显示 `t`，配音读 `tts`（例：`哪只`→`哪支`，避免读成 zhǐ）
2. 跑：
   ```bash
   ./scripts/fupan/run.sh                       # edge-tts 配音(默认, 走 7897 代理)
   TTS_ENGINE=kokoro ./scripts/fupan/run.sh     # 离线 Kokoro 配音
   SKIP_VO=1 ./scripts/fupan/run.sh             # 只改了画面, 复用配音
   SKIP_RENDER=1 ./scripts/fupan/run.sh         # 只生成, 去 Studio 看
   CONCURRENCY=2 ./scripts/fupan/run.sh         # 渲染并发(建议 1–2)
   ```
3. 字幕逐字点亮、人物口型、关键词弹跳、图表/镜头推拉的触发点都按 `timing.json` 自动对齐。
   **场景的数量和顺序**是写在 `build.mjs` 里的（每个场景 id 对应一段画面）；只改句子内容不用碰代码，增删场景需要同时改 `build.mjs`。

## 三、配音引擎

| 引擎 | 音质 | 联网 | 准备 |
|---|---|---|---|
| `edge`（默认） | 好（云扬/云健/云希） | 需要连微软，`EDGE_PROXY=http://127.0.0.1:7897` | `pip install edge-tts` |
| `kokoro` | 一般，偏机械 | 不需要 | `pip install kokoro-onnx soundfile "misaki[zh]"`，下载模型到 `KOKORO_DIR`（见下） |

Kokoro 中文模型（~380MB，从 GitHub Releases 下）：
```bash
mkdir -p ~/models/kokoro && cd ~/models/kokoro
curl -LO https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.1/kokoro-v1.1-zh.onnx
curl -LO https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.1/voices-v1.1-zh.bin
```
> 坑：Debian/Ubuntu 系统 python 装 `jieba` 会报 `install_layout`，用 venv 装即可。
> 坑：Kokoro 默认语速偏慢（~4.4 字/秒），`speed` 设 1.38–1.42 才接近短视频语速（~6 字/秒）。

音色在 `script.json → engines.<engine>.voices` 里按角色配。

## 四、画面设计要点（为什么这么做）

| 手法 | 目的 |
|---|---|
| 第 0 帧就是完整封面（大字 + 困惑的小于） | 平台首帧/封面直接可用，前 1 秒不空 |
| 开头悬念句 + "看错了东西"红章 | 3 秒钩子 |
| 逐字点亮字幕 + 关键词金色弹跳 | 借鉴 Claude Design Animations 的"按词同步"，替代写死秒数 |
| 深夜书房 / 茶室两个实景 + 原创人物口型 | 剧情感，不是 PPT |
| 散户群像（先欢呼→集体低开时惊恐）、资金接力小人 | 把抽象概念拟人化 |
| 每场景缓慢推镜 + 关键词 punch-in + 高潮闪光 | 2–3 秒一次视觉变化，防划走 |
| 配乐和弦随剧情（失败段转小调）、人声闪避、高潮前抽空蓄力 | 情绪曲线 |
| 结尾 A/B/C/D 选项 + 评论框打字 + 点关注 | 低门槛评论引导 |
| 红涨绿跌、图表标"示意数据"、底部"不构成投资建议" | A 股习惯 + 合规 |

## 五、Remotion 里怎么跑 GSAP（原理）

`build.mjs` 产出的是一段普通 DOM + CSS + 一个**暂停的** GSAP 时间线。`FupanStory.tsx`：
1. `useLayoutEffect` 挂载时注入 DOM、构建时间线（只一次）；
2. 每帧 `useLayoutEffect`：按元素的 `data-start/data-duration` 设可见性，然后 `tl.seek(frame / fps)`。

时间完全由帧号决定 → 确定性渲染、可任意跳帧、可分段并发。CSS 全部加 `.fp-scope` 前缀，不污染 Studio。

## 六、踩坑

- **类名撞车**：逐字字幕 span 曾用 `.ch`，和图表面板 `.ch` 冲突 → 字幕塌成一竖条、图表变暗。现在用 `.cc`。新加样式先 grep 一下。
- **npm 镜像**：`package-lock.json` 解析地址是 npmmirror；在连不上 npmmirror 的环境里临时把 lock 里的域名替换成 `registry.npmjs.org` 再 `npm ci`。
- **edge-tts 网络**：云端/沙箱环境通常连不上 `speech.platform.bing.com`（403），此时用 `TTS_ENGINE=kokoro`。
- **单文件 >20MB**：成片 CRF 18 约 30MB；发给别人/传平台可再压：`ffmpeg -i in.mp4 -c:v libx264 -crf 21 -maxrate 2.8M -bufsize 5.6M -c:a aac -b:a 160k -movflags +faststart out.mp4`（~11MB，平台会再压一次，肉眼无差）。
