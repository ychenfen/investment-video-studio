# 环境配置

复现本工作台需要的环境。机器：macOS 15.7.4 / Apple M4 Pro。

## 运行时

| 项 | 值 | 说明 |
|---|---|---|
| Node | v24.3.0 (`/opt/homebrew/bin/node`) | Remotion 跑在这上面 |
| 系统 Python | 3.9.6 (`/usr/bin/python3`) | **太老, 别用**(装不了 edge-tts) |
| Homebrew Python | 3.13 (`/opt/homebrew/bin/python3.13`) | **用这个**装 edge-tts/akshare |
| pip 用户脚本目录 | `~/Library/Python/3.13/bin/` | edge-tts 命令在这(不在 PATH, 用全路径) |

## 网络 / 代理

- 系统代理：**127.0.0.1:7897**（不是常见的 7890；从 `scutil --proxy` 和环境变量 `HTTP_PROXY` 查到）
- 墙外站（YouTube / stooq）要走代理：
  ```bash
  export http_proxy=http://127.0.0.1:7897 https_proxy=http://127.0.0.1:7897 HTTP_PROXY=http://127.0.0.1:7897 HTTPS_PROXY=http://127.0.0.1:7897
  ```
  **ffmpeg 只认小写** `http_proxy`/`https_proxy`（拉 googlevideo 流时关键）
- 国内站（akshare 东财/新浪）**别走代理**：调用前 `env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY`
- 镜像源：npm → `https://registry.npmmirror.com`；pip → `https://mirrors.aliyun.com/pypi/simple`（清华 pip 源本机 SSL 报错）

## 渲染引擎

- **系统 Google Chrome**：`/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`
- 渲染必带 `--browser-executable="..."`（Remotion 自带 chrome headless shell 下载被墙）
- yt-dlp 也靠它读 cookies 过 YouTube 反爬（`--cookies-from-browser chrome`）

## 字体

- 英文：`public/fonts/` 下的 woff2（Poppins 400/600/700 + Lora 400/500，来自 @fontsource），用 @remotion/fonts 的 `loadFont` 加载（见 `src/theme.ts`）
- 中文：系统 PingFang SC（`font-family: "PingFang SC", "Hiragino Sans GB"`），系统 Chrome 渲染能用

## remotion.config.ts 关键配置（已写好）

```ts
import {Config} from '@remotion/cli/config';
Config.setConcurrency(1);                          // 多 tab + 系统 Chrome 不稳 -> 单并发
Config.setVideoImageFormat('png');                 // jpeg 中间帧会压糊画面
Config.setChromiumOpenGlRenderer('angle');         // WebGL 在 headless 渲染需要
```

## 渲染命令模板

```bash
cd remotion
npx remotion render src/index.ts <CompositionId> out/x.mp4 \
  --browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --concurrency=1 --crf 16 --timeout=120000
```

- `--crf 16` 高画质（数值越低越清晰）
- WebGL 水波段渲染慢（每帧 Three + shader + 截图），1080 帧级别可放后台 `run_in_background`
- composition 全是 1080×1920 / 30fps（竖屏）；Anthropic 横屏 Main 是 1920×1080
