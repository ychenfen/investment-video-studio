# 依赖与下载清单

今晚装的、下的每一样东西：版本、来源、安装命令、用途、为什么。全部在 macOS 15.7.4 / Apple M4 Pro 上实测。

## 一、npm 包（在 remotion/ 目录）

Remotion 全家版本**必须一致**（混版会导致渲染页面崩，见踩坑文档）。统一锁在 **4.0.469**（npmmirror 上 cli/fonts 没有 4.0.471，所以全降到 469）。

| 包 | 版本 | 用途 |
|---|---|---|
| remotion | 4.0.469 | 核心，React 写视频 |
| @remotion/cli | 4.0.469 | 渲染命令 `npx remotion render` |
| @remotion/three | 4.0.469 | 在 Remotion 里跑 Three.js / WebGL |
| @remotion/fonts | 4.0.469 | 加载本地字体（处理了渲染环境检查） |
| three | 0.169.0 | WebGL / Three.js 本体 |
| @react-three/fiber | 8.18.0 | React 写 Three（@remotion/three 依赖） |
| @fontsource/poppins | 5.2.7 | Poppins woff2 字体文件（离线） |
| @fontsource/lora | 5.2.8 | Lora woff2 字体文件（离线） |
| react / react-dom | 18.3.1 | React（Remotion 4 用 React 18） |

安装命令（**关键：用 npmmirror 源，官方源/清华源在本机网络下不稳**）：

```bash
cd remotion
# Remotion 核心 (首次)
npm i remotion@4.0.469 @remotion/cli@4.0.469 react@18 react-dom@18 --registry https://registry.npmmirror.com
# 字体 (离线 woff2)
npm i @fontsource/poppins @fontsource/lora --registry https://registry.npmmirror.com
# 本地字体加载器
npm i @remotion/fonts@4.0.469 --registry https://registry.npmmirror.com
# WebGL (--legacy-peer-deps 绕过 peer 版本冲突)
npm i @remotion/three@4.0.469 three@0.169.0 @react-three/fiber@8 --legacy-peer-deps --registry https://registry.npmmirror.com
```

node_modules 已含在本工作台（374M），clone 即可跑，不用重装。重装时务必加 `--registry https://registry.npmmirror.com`。

## 二、Python 包（用 Homebrew Python 3.13，不是系统 3.9）

系统 Python 3.9 太老装不了 edge-tts，必须用 `/opt/homebrew/bin/python3.13`。

| 包 | 版本 | 用途 |
|---|---|---|
| edge-tts | 7.2.8 | 微软免费 TTS，生成中文配音 |
| akshare | 1.18.64 | 抓 A 股 / 美股真实行情数据 |
| pymediainfo | 7.0.1 | akshare 依赖 |

安装命令（**阿里源**，`--break-system-packages` 绕过 PEP 668）：

```bash
/opt/homebrew/bin/python3.13 -m pip install --user --break-system-packages edge-tts akshare -i https://mirrors.aliyun.com/pypi/simple
```

edge-tts 命令在 `~/Library/Python/3.13/bin/edge-tts`（不在 PATH，用全路径调）。

## 四、字体

- **英文**：Poppins（标题）+ Lora（正文），来自 @fontsource 的 woff2，复制到 `remotion/public/fonts/`：
  - poppins-400/600/700.woff2、lora-400/500.woff2
  - 复制命令：`cp node_modules/@fontsource/poppins/files/poppins-latin-{400,600,700}-normal.woff2 public/fonts/poppins-{400,600,700}.woff2`
  - 为什么本地：Google Fonts 的 gstatic 在 chrome 渲染时被墙，必须本地 woff2
- **中文**：PingFang SC（系统字体 `/System/Library/Fonts/PingFang.ttc`），CSS `font-family: "PingFang SC"`，系统 Chrome 渲染能用，无需下载

## 六、为什么处处用镜像源

本机网络：清华 pip 源握手报 SSL（LibreSSL 兼容问题）；官方 npm 源不稳。验证可用的：
- npm → `https://registry.npmmirror.com`（阿里 npm 镜像）
- pip → `https://mirrors.aliyun.com/pypi/simple`（阿里 pip 镜像）
- 系统代理在 **127.0.0.1:7897**（不是常说的 7890），爬 YouTube/stooq 等墙外站要走它（环境变量 `http_proxy`/`https_proxy`，注意 ffmpeg 只认小写）
